# AirPlay для Alice Homebrew

Экспериментальный **аудиоприёмник AirPlay** для Яндекс Станции Мини первого поколения, YNDX-0004, Linux ARM64. Нужен Homebrew 0.3.0 или новее и готовый ADB root. Версия `1.0.0-beta.3`.

После установки из официального каталога откройте конфиг, задайте имя, при необходимости пароль и ограничение громкости, сохраните и включите плагин. iPhone/iPad/Mac и колонка должны находиться в одной локальной сети без изоляции клиентов Wi-Fi. В Пункте управления iPhone откройте список устройств вывода звука AirPlay и выберите `Alice Mini` (или заданное имя).

По умолчанию выбран **«Совместно с Алисой (штатный микшер)»**. Shairport передаёт PCM в системный `/system/workdir/bin/aplay`, который использует ту же библиотеку ALSA и `dmixer`, что и штатная Алиса. Это позволяет нескольким проигрывателям делить аудиовыход. Плагин не останавливает голосовые процессы, не включает ранее отключённую Алису и не меняет системные конфиги. Рабочий проигрыватель запускается только при поступлении музыки и закрывается после двух секунд без PCM.

Старые конфиги при обновлении получают совместный режим по умолчанию; имя, пароль, громкость и порт сохраняются. В Homebrew 0.5.1+ откройте магазин, обновите каталог и нажмите «Обновить» у AirPlay.

Если Алиса намеренно отключена или штатного микшера нет, вручную выберите **«Прямой выход (Алиса отключена)»**. Только в этом режиме применяется выбор PCM 0 TDM-B / PCM 1 TDM-C. Прямой режим может конфликтовать со штатным воспроизведением; скрытого переключения на него при ошибке общего микшера нет. Сохранение конфига перезапускает включённый плагин. По умолчанию максимум ограничен −10 дБ; начните с небольшой громкости на телефоне.

Это AirPlay classic/RAOP для звука, без зеркалирования экрана, без заявления совместимости AirPlay 2, multiroom и DRM-сервисов. Владелец подтвердил воспроизведение с iPhone в предыдущих beta. Совместный режим beta.3 проверен двумя одновременными потоками цифровой тишины через штатный микшер Мини 1. На Мини 1 с прошивкой `1.369.4.50.4794692641.20261021` и исправлениями ALSA/SRC владелец также подтвердил музыку по AirPlay и слышимый ответ Алисы во время воспроизведения; подробности ниже. Установщик Homebrew не устанавливает этот плагин автоматически.

## Доступ и зависимости

Нативный сервис работает с root без песочницы. Назначение: аудиовыход, TCP/UDP и mDNS в локальной сети. Микрофон, камера, датчик и облачные сервисы ему не нужны, запись звука не выполняется. Перед включением менеджер запрашивает явное подтверждение полного системного доступа.

Статические ARM64 Shairport Sync и Go-сервис обнаружения встроены в `plugin.elf`. Совместный режим дополнительно использует файлы штатной прошивки: `/system/workdir/bin/aplay`, `/system/vendor/quasar/libs/libasound.so.2`, `/usr/share/alsa/alsa.conf` и созданный прошивкой `/tmp/alsa/dmixer.conf`. Они не входят в распространяемый пакет. Использование именно штатной библиотеки сохраняет совместимость общей памяти dmix со штатными процессами. Прямой режим использует встроенную ALSA. Системные ALSA-конфиги не переписываются. Рабочие файлы остаются в каталоге данных плагина. Используются TCP-порт из настроек (7000 по умолчанию), UDP RTP/контроль/синхронизация Shairport и UDP 5353 mDNS. Доступ из интернета для приёма музыки не требуется.

На проверенной прошивке Мини 1 `1.369.4.50.4794692641.20261021` штатный `aplay` не указывает версии символов ALSA и связывается с устаревшими вариантами API. Симптом: AirPlay подключён, измеритель видит PCM, но динамик молчит; параметры частоты и буфера некорректны. Для проверенной пары `aplay`/`libasound` плагин создаёт приватную копию библиотеки в `alsa-compat/` внутри своих данных и исключает устаревшие дубли символов только из этой копии. Код библиотеки, ABI общей памяти dmix и системные файлы сохраняются; копию использует только дочерний `aplay`. Пара определяется по SHA-256 обоих файлов. На других прошивках сохраняется прежний путь без подмены библиотеки. Проверки и ограничения: [VALIDATION-alsa-compat.md](VALIDATION-alsa-compat.md).

На этой же проверенной паре библиотек совместный режим использует sinc-преобразование 44,1 → 48 кГц через полную штатную libsamplerate вместо линейного алгоритма, ослабляющего высокие частоты. Для дочернего `aplay` создаются приватные копии в `alsa-rate/`; системные файлы и библиотека Алисы не меняются. Преобразователь включается только при совпадении SHA-256 исправленной ALSA, полной libsamplerate и модуля SRC. При отсутствии или другой версии этих файлов сохраняется линейный путь. Измерения, нагрузка и ограничения: [VALIDATION-resampler.md](VALIDATION-resampler.md).

Основные компоненты: Shairport Sync 5.6.1, FFmpeg 8.1.3 (ALAC/PCM, без программ/сетевых демультиплексоров), ALSA 1.2.16.1, OpenSSL 3.5.6, libconfig 1.8.3, popt 1.19, HashiCorp mDNS 1.0.7. Устаревшие декодеры Hammerton/Apple ALAC и tinysvcmdns не включены. При изменении зависимостей проверяйте актуальные исправления upstream.

## Проверка и исходники

Проверки версии, RTSP/Apple-Challenge и формирования RAOP TXT выполняются под QEMU на ПК; они не заменяют тест реальной передачи и динамика. Источники менеджера и плагина открыты. Отдельный архив `AirPlay-1.0.0-beta.3-source.tar.gz` в релизе содержит точные исходные архивы зависимостей, изменения и инструкции сборки/перелинковки. Нельзя заменять его только ссылками на upstream при распространении готового пакета.

Сборка приёмника: `bash plugins/airplay/build-receiver.sh`. Нужны Linux, ARM64 cross GCC/G++, make, pkg-config, autoconf, automake, libtool, perl, flex/bison и curl. Затем `python3 plugins/airplay/build-plugin.py` из корня репозитория (Go 1.26.5 в PATH). Сборка не устанавливает и не включает плагин на колонке.

## Музыкальное кольцо

RMS, peak и 12 частот передаются только в локальный Homebrew 0.5.0+. В совместном режиме измеряется поток stereo S16_LE / 44100 Гц перед штатным проигрывателем; в прямом режиме работает прежний измеритель S32_LE / 48000 Гц внутри Shairport. Микрофон и запись звука не используются. Очередь измерений ограничена одним пакетом и не задерживает звук при недоступном менеджере. Это измерение декодированного AirPlay, а не универсальный перехват других проигрывателей.
