# DESIGN.md — Alice Homebrew

Источник значений для веб-интерфейса менеджера (`internal/homebrew/web`). Перед любой правкой
интерфейса прочитайте этот файл и берите значения отсюда по имени токена. Код токенов —
`:root` в `web/style.css`; файл и код меняются вместе.

## Direction

**Direction** · deal 6401fafa, material 3/3 sodium-lamp → «ночная мастерская, где светится только кольцо станции»
- Scene · человек с root-доступом вечером за столом: ноутбук, станция рядом, по LAN ставит плагины и смотрит, что сейчас работает
- Built · rank #3 of 7 (road not taken, #1: светлая шалфейно-зелёная панель с карточками — прежний вид)
- Type · системный сжатый гротеск (Bahnschrift SemiCondensed / Roboto Condensed) для заголовков и цифр, Segoe UI / Roboto для текста, Cascadia Mono / Roboto Mono для версий и хешей; без загрузки шрифтов — менеджер работает офлайн с колонки, CSP `self`
- Palette · committed: коричнево-чёрная ночь, натриевый оранжевый как единственный сигнал действия, тёплый белый текст; холодный голубой только для меток yam v2
- Structure · triage-список с панелью деталей; выключатель плагина в строке списка и рядом с названием. Убрано (unslop-проход 28.10.2026): строка метрик под шапкой, плитки-иконки строк, метка «Homebrew» у своих плагинов, технический ID и архитектура в шапке
- Job · try: поставить плагин или пакет yam и включить его; главная кнопка всегда в панели деталей справа
- Signature · логотип и превью — светодиоды станции в их настоящей раскладке (Мини 1: 8 по кругу + 4 под логотипом; Миди 24; Мини 2 — 6; Лайт и Лайт 2 — 3), живой кадр плагина
- Motion · как свет лампы: включается быстро, гаснет мягко; без пружинистых прыжков у крупных поверхностей. Нажатия — interaction kit
- Absent · отзывы, рейтинги, скриншоты плагинов (каталоги их не содержат) — не рисуем

Target: точный, ночной, рабочий. Avoid: маркетинговый, «стеклянный», игрушечный.

## Spacing

Шкала: 4, 8, 12, 16, 24, 32, 48 (`--s-1` … `--s-7`). Внутри контрола 8, между строками списка 0
(разделитель), между элементами группы 12, между группами 24, отступ панели 24 (16 на телефоне).

## Alignment

Список: значок 32 px на левой линии, текст на второй линии (+12), справа колонка состояния
с выравниванием по правому краю. Поля настроек: подпись над полем, общая левая линия.
Текст в кнопках центрируется flex-ом по высоте контрола.

## Radii

`--r-control` 6 (кнопки, поля, метки), `--r-panel` 10 (панели, диалог), `--r-pill` 999 (переключатель, светодиоды).
Вложенный элемент не крупнее радиуса родителя.

## Borders and depth

Линия 1 px. Глубина — сменой поверхности (ground → surface → raised), без теней. Единственная тень — у диалога (`--shadow-dialog`).

## Icons

Собственный набор: 12-точечное кольцо (бренд), геометрические знаки в 16/20 px, линия 1.5 px,
`currentColor`. Значок поддерживает подпись, не заменяет её. Эмодзи не используются.

## Layout

Верхняя панель 56 px. Контент — две колонки: список 400 px (min 340) и детали
(1fr), максимум 1440 px. До 960 px — одна колонка: выбранный элемент открывается вместо
списка с кнопкой «Назад». Безопасные отступы на телефоне 16 px.

## Motion

Interaction kit (`web/kit.css`, `web/kit.js`), токены `--ui-*` переназначены в `style.css`.
- `--m-fast` 120 ms — цвет, наведение; `--m-base` 220 ms — появление панели; `--m-exit` 140 ms — уход.
- Easing: `--ui-ease-out` для появления, `--ui-spring-snap` для индикаторов вкладок и переключателя.
- Панель деталей при смене элемента: crossfade + сдвиг 6 px. Диалог растёт из кнопки.
- Светодиоды кольца меняют цвет за 150 ms (как реальный кадр).
- Reduced motion: сдвиги и масштаб убираются, остаются смена цвета и прозрачности.
- Пул эффектов не используется.

## Voice and copy

Коротко, по делу, на «вы» без обращения. Подписи — существительные или глаголы действия
(«Установить», «Удалить»). Подзаголовки страниц не пересказывают заголовок. Пояснения только
когда есть факт: ограничение, последствие, требование (например, «yam v1 больше не поддерживается»).
Числа: `ru-RU`, единицы КиБ/МиБ/ГиБ.

## Prohibitions

Без hero-блоков, сеток одинаковых карточек, градиентного текста, свечений, eyebrow-меток над
заголовками, капса с разрядкой, эмодзи-иконок, нативных `confirm()`.

## Code mapping

`web/style.css :root` — все токены; `web/kit.css` — interaction kit; `web/app.js` — компоненты
(`button()`, `tag()`, `row()`), никаких литералов цвета в JS, кроме кадров светодиодов.

## Discrepancies and exceptions

- Цвета светодиодов приходят из кадра плагина — это данные, не токены.
- Порядок 8 внешних светодиодов Мини 1 на плате не проверен: превью рисует их по часовой стрелке сверху.
- Раскладки sysfs (Лайт, Лайт 2, Мини 2, Миди) взяты из yamd v1 и не проверены на железе в этом проекте.
- Метки выводятся только когда несут информацию: сторонний источник, локальный пакет, yam v2/v1, обновление, ошибка.
- Страница каталога для GitHub Pages (`web/pages.html`) использует тот же `style.css`, но её вёрстка не переделывалась в этой итерации.
