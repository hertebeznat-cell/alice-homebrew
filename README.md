# Alice Homebrew 6.0.1 «newlife»

В 6.0.0 новый интерфейс, поддержка других станций с root (модель определяется автоматически, подсветка — на Мини 1, Лайт, Лайт 2, Мини 2 и Миди) и пакеты yam v2/v1 в общем магазине. После обновления менеджер один раз сам ставит yam v2 и yamd (yam v1) с проверкой SHA-256. Подробности — в [RELEASE_NOTES.md](RELEASE_NOTES.md), оформление — в [DESIGN.md](DESIGN.md).

Станции на Android (например, Станция 1-го поколения и Станция Макс) не поддерживаются: установщик их распознаёт и останавливается.

Установка на другую станцию: `py scripts/install-speaker.py --install --autostart` сам выбирает сборку под процессор; если модель не определилась, добавьте `--platform ID` (например `yandexmini_2`, `cucumber`, `plum`).

В 0.5.4 последние строки журнала сохраняются после остановки плагина и перезапуска менеджера. Журнал, ошибка и кнопка включения обновляются в открытой панели без сброса несохранённого конфига. Для «Алиса: старые прошивки» beta.2 комплект скачивается самой колонкой с GitHub; компьютерный bundle-server больше не нужен.

В 0.5.3 менеджер автоматически удаляет распакованные исполняемые файлы старых версий плагинов при запуске и после обновления. Текущая версия, настройки и данные плагина сохраняются. Пакет предыдущей версии остаётся для отката; при откате рабочие файлы создаются заново. Размер на диске включает пакет, рабочие файлы, данные плагина и архив для отката, поэтому отличается от размера скачивания.

В 0.4.0 добавлено автоматическое обновление менеджера со стабильных релизов этого репозитория каждые 5 часов. Настройки, плагинные пакеты и ADB root сохраняются. Есть проверка SHA-256, резервная версия и автоматический откат при отказе запуска. В настройках доступны статус, время следующей проверки и ручная проверка. [Подробнее об обновлениях и выпуске новых версий](docs/MANAGER_UPDATES.md).

Менеджер плагинов работает на самой Яндекс Станции Мини 1 (YNDX-0004), открывается по IP колонки на порту 8088, без входа и токена. Требуется уже настроенный ADB root. Здесь опубликован только Homebrew: средства получения root и прошивки в репозиторий не входят.

Официальный источник подключён автоматически. Плагины можно устанавливать из подписанных каталогов, локального `.aliceplugin` или по ссылке с загрузкой самой колонкой. Интерфейс на русском и английском, настройки сохраняются по схеме плагина. Есть информация о свободном месте/ОЗУ, предложение удалить крупные плагины при нехватке места, откат версии и несколько источников.

В 0.3 добавлен нативный SDK для звука, микрофонов, датчика, кнопок, подсветки, сети и других устройств Linux. Нативный код работает с полным root-доступом после явного подтверждения. WASM SDK 1 остаётся изолированным. Перечень доступа не гарантирует наличие драйвера для любой аппаратной ревизии: смотрите совместимость конкретного плагина.


Менеджер плагинов для Яндекс Станции Мини 1, YNDX-0004. Служба работает **на самой колонке**, браузер открывает `http://IP-КОЛОНКИ:8088`. Вход, пароль и `admin-token.txt` для менеджера колонки не нужны.

Для установки нужен уже работающий ADB root. Этот проект содержит только Homebrew: средства получения root и прошивки в него не входят. Установка Homebrew сохраняет штатную Алису и остальные приложения.

## Алиса на старой прошивке: экспериментальный плагин

[Alice Legacy Fix 0.1.0-beta.2](plugins/alice-legacy-fix/README.md) запускает новый голосовой стек в отдельном RAM-окружении на одной поддерживаемой прошивке Mini 1 2022 года. [Плагин beta.2](https://github.com/hertebeznat-cell/alice-homebrew/releases/tag/alice-legacy-fix-v0.1.0-beta.2) доступен в официальном каталоге. Для запуска оставьте адрес комплекта пустым: колонка скачает его с GitHub с проверкой SHA-256; дополнительная программа на ПК не нужна.

По умолчанию выполняется только проверка совместимости. Исходная прошивка сохраняется, предусмотрен возврат к штатной Алисе. Исправление голосовых ответов на проблемном устройстве ещё не подтверждено; подробные ограничения и порядок запуска приведены в инструкции плагина. Для сохранения журналов после ошибки обновите менеджер до 0.5.4.

## Возможности

- Наш официальный источник добавлен по умолчанию. Его подпись проверяется закреплённым публичным ключом; каталог доступен прямо с GitHub без отдельного сервера.
- Несколько источников: добавление по ссылке на репозиторий, сайт или JSON. Для стороннего источника показываются подпись, ключ и отдельное подтверждение доверия. Название «Official» или размещение на GitHub не дают официальную отметку.
- Установка одобренных версий, загрузка своего `.aliceplugin` через браузер и скачивание самой колонкой по URL, включая локальную сеть.
- В настройках видны свободный диск, доступная оперативная память, размер Homebrew и размеры пакетов/версий для отката.
- При нехватке места установка не пишет пакет и предлагает выбрать плагины для удаления, начиная с самых больших. Вместе с выбранным плагином удаляется его конфиг; другие файлы колонки менеджер не удаляет.
- Визуальные конфиги: цвет и HEX, ползунок и точное число, переключатель, список, текст. Значения сохраняются на колонке, переживают перезапуск и скачиваются в JSON.
- Обновление с совместимым переносом настроек, отключение, удаление и возврат одной предыдущей версии. Отзывы и ревизии хранятся отдельно для каждого источника.
- Русский и английский интерфейс.

SDK 1 предоставляет `led.ring` и `log.write`. Плагин — WebAssembly-модуль с ограниченной памятью и временем tick. Shell, файловая система, сеть и WASI ему не предоставляются. Это ограничения SDK, а не гарантия отсутствия всех уязвимостей: сторонние пакеты требуют проверки.

## Установка на Мини 1

Скачайте и распакуйте готовый архив Windows/Linux. На компьютере нужен Python 3 для отдельного установщика. В приложении получения root установщик Homebrew может вызываться автоматически; этот репозиторий работает и отдельно на уже подготовленной колонке.

```powershell
# Только проверка подключения, архитектуры, root и места:
py scripts/install-speaker.py
# Установка и автоматический запуск после перезагрузки:
py scripts/install-speaker.py --install --autostart
```

На Linux замените `py` на `python3`. ADB и ключ подхватываются из настроек Station Mini Root или передаются через `--adb`, `--key`, `--serial`. По умолчанию используется существующий сервер ADB на порту 5037; он не останавливается.

Установщик проверяет ARM64/Amlogic и ADB root, требует место под бинарник плюс 20 МиБ, проверяет SHA-256 после передачи и готовность HTTP. Служба и данные размещаются в `/data/alice-homebrew`. При `--autostart` устанавливается только её собственный `/etc/init.d/S98alice-homebrew`; чужой одноимённый файл не заменяется. Сервис запускается через `setsid` для совместимости со старым ADB.

После установки программа напечатает настоящий адрес колонки. Откройте его в браузере. Установка, запуск после перезагрузки, сохранение состояния, WASM-пример и I2C-вызовы проверены на Мини 1. Штатные световые эффекты Алисы могут перекрывать плагин: менеджер не останавливает `platformd`.

## Магазин и свои источники

Откройте **«Магазин»**. Наш источник уже добавлен; при необходимости нажмите **«Обновить каталог»**. Его адрес:

```text
https://raw.githubusercontent.com/hertebeznat-cell/alice-homebrew/main/docs/catalog/v1.json
```

Для своего каталога откройте **«Настройки → Добавить источник»** и вставьте ссылку. JSON и публичный ключ обычно определяются автоматически. Проверьте результат и подтвердите доверие стороннему владельцу. Имя репозитория не заменяет проверку подписи.

Для локального файла используйте **«Добавить пакет»** или **«По ссылке»**. Во втором случае скачивает служба на колонке; для файла на ПК нужен IP компьютера, а не `localhost`. Локальные пакеты требуют отдельного согласия. После установки плагин выключен; включите его в карточке.

Каталоги плагинов и yam обновляются при старте, каждые 3 часа и по запросу пользователя. Установленным плагинам интернет не нужен. Удаление источника сохраняет установленные плагины и не сбрасывает отзывы/максимальную ревизию этого источника.

## Предпросмотр на компьютере

```powershell
.\bin\alice-homebrew-windows-amd64.exe station --listen 127.0.0.1:8088 --data .\station-data
```

На Linux используйте `bin/alice-homebrew-linux-amd64`. Откройте `http://127.0.0.1:8088` — без входа. Предпросмотр исполняет тот же WASM и рисует созданные им кадры; аппаратный I2C не открывается.

## Панель владельца источника

```powershell
.\bin\alice-homebrew-windows-amd64.exe store --data .\moderator-data
```

Откройте `http://127.0.0.1:8089`. Это отдельная локальная панель модератора на ПК, имеющая доступ к закрытому ключу подписи. Только у неё есть код в `moderator-data/admin-token.txt`; он не относится к менеджеру на колонке.

Проверяйте исходники и работу конкретной версии, при необходимости подключите установленный ClamAV флагом `--scanner`. После ручного одобрения экспортируйте сайт через вкладку **«Публикация»**. В экспорт не входят ключ и код доступа. Публикуйте `/docs` и шаблон GitHub Issues, сохраняя папку модератора отдельно. [Пошаговый гайд](docs/SOURCE_GUIDE.md).

## Сборка из исходников

Go 1.26+, без CGO. Веб-интерфейс встроен в бинарник; Node.js/npm не нужны.

```bash
go mod download
go test ./...
go build -o alice-homebrew ./cmd/alice-homebrew
```

Для колонки:

```bash
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -ldflags='-s -w' -o dist/alice-homebrew-linux-arm64 ./cmd/alice-homebrew
```

Пример — в `examples/ring-studio`, его сборка — в `scripts/build-example.sh`. Объяснение манифеста и ABI — в [гайде разработчика](docs/PLUGIN_GUIDE.md).

Ограничения: до 8 установленных и 4 активных плагинов, до 8 добавленных источников и 32 записей их истории; архив WASM до 4 МиБ (нативный до 16 МиБ), WASM до 2 МиБ, память одного модуля до 2 МиБ, tick 20 мс. Менеджер оставляет минимум 8 МиБ диска. Размер плагина в интерфейсе — размер пакета и сохранённой версии; память WASM не является полной оценкой расходов рантайма.

## Обновления плагинов

В «Моих плагинах» нажмите «Обновить каталог». Для новой версии из исходного источника появится «Обновить» — также в настройках плагина и магазине. Конфиг, состояние включения и предыдущая версия сохраняются. Магазин показывает последнюю версию на каждый источник. См. RELEASE_NOTES.md для условий выпуска 0.5.1 без тестов.

## Ошибка сертификата GitHub

0.5.2 включает собственные доверенные CA для HTTPS. Если старая версия не обновляется из-за x509 unknown authority, используйте Station Mini Root 0.3.11 → «Обновить только Homebrew (ADB root)» на прежнем ПК с сохранённым ключом. Подключение — обычный ADB, без якоря и перепрошивки system. См. RELEASE_NOTES.md.
